Entidade: Fazenda
Armazenamento: Array de objetos JSON no localStorage

Campos:
- id: Identificador único gerado via Date.now() (Number)
- nome_fazenda: Nome da propriedade rural (String)
- municipio: Cidade da propriedade (String)
- area_total: Área em hectares (Number)

Exemplo de dados iniciais:
[
  { "id": 1730925200001, "nome_fazenda": "Fazenda Santa Cruz", "municipio": "Ribeirão Preto", "area_total": 250.5 },
  { "id": 1730925200002, "nome_fazenda": "Sítio das Águas", "municipio": "Uberlândia", "area_total": 85.0 }
]
